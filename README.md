# 成田空港 欠航時ホテル・バス手配ツール｜成田機場停飛住宿分配工具

航班臨時停飛（欠航）時，協助地勤在數分鐘內產生「全機數百名旅客的飯店分配 + 巴士接送批次」方案的純前端網頁工具。

## 功能

- 輸入總人數、C/F 艙、家庭組數、輪椅需求、組員數、巴士容量與台數 → 一鍵產生分配方案
- 分配優先序：組員（指定飯店）→ 無障礙 → C/F 艙 → 家庭（**絕不拆散**）→ 經濟艙（依車程貪婪集中）
- 巴士排班：自動計算每飯店車次與發車波次（T+分鐘），估算最後回程時間
- Leaflet 地圖：三航廈與各飯店位置、分配人數（標記大小）、狀態（顏色）
- 方案驗證：容量缺口、溢出警示、楽天線上空房交叉比對（「需電話確認」標黃）
- 中日雙語並列介面、列印每飯店乘車名單（`Ctrl+P`）
- **離線可用**：內建 14 家成田周邊飯店估計資料；楽天 API 僅為加值訊號

## 使用方式

直接開啟 `index.html`（雙擊即可），或部署於任何靜態主機（GitHub Pages）。

### 楽天即時空房（選用）

1. 到 [楽天ウェブサービス](https://webservice.rakuten.co.jp/) 免費註冊取得 `applicationId`（不需信用卡）
2. 貼入頁面右上欄位按「保存・テスト」——key 只存在瀏覽器 localStorage
3. 計算時會自動以 roomNum 探測法（10→5→1）將各飯店線上空房分級為 ≥10 / 5–9 / 1–4 / 0

未設定 key 時以離線模式運作，功能不受影響。

### 自我測試

開啟 `index.html?selftest=1`：執行分配引擎斷言（守恆檢查、容量不足、巨型家庭、巴士波次等 8 組情境）並自動跑一次預設計算。

## ⚠ 重要注意事項

- `js/hotels-data.js` 中的**房數、無障礙房數、電話號碼皆為估計值**，正式運用前務必逐家電話核對並修正。
- 楽天線上可見空房遠低於電話可徵用房數（航空公司協議房不會上架），僅供排序參考，**實際徵用一律以電話確認為準**。
- 車程分鐘為估計值，深夜／交通管制時請自行斟酌。

## 架構

無框架、無 build step 的純靜態頁面：

```
index.html          頁面骨架（中日雙語標籤直接寫死）
css/style.css       版面、警示配色、列印用乘車名單樣式
js/hotels-data.js   飯店靜態資料（維護點：新增／修正飯店在這裡改）
js/allocator.js     分配引擎（純函式，含 runSelfTests）
js/rakuten-api.js   楽天 API：節流 1.1s、429 退避、JSONP 備援、hotelNo 自動解決
js/map.js           Leaflet 地圖層
js/i18n.js          動態訊息中日字典
js/app.js           表單／渲染／localStorage 接線
```
